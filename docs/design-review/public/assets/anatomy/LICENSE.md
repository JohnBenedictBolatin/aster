# Aster anatomy asset credits

Aster bundles anatomical reference models locally so the optional body explorer works offline. The model data and original application code have separate licenses.

## Body surface, skeleton, muscles, digestive structures, and major vessels

**BodyParts3D 4.0**, © The Database Center for Life Science (DBCLS), sourced from the official 99% reduced polygon mesh archive. Required attribution: “BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International.” The [official archive license](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html) states CC BY 4.0 (updated 2025-02-27) and permits redistribution and adapted works with attribution.

The original OBJ headers also contain a CC BY-SA 2.1 Japan notice. The current official archive license page states CC BY 4.0; this difference is retained in the record. For this demo, selected source parts were grouped into toggleable systems, triangulated, recentered and uniformly scaled, transformed from Z-up to Y-up, assigned illustrative colors, and exported as GLB. No anatomy was generated.

## Heart

The heart model is from OrganUI’s [heart-3d explorer](https://github.com/organui/heart-3d), using BodyParts3D 4.0 model data under CC BY 4.0. The source meshes remain separate for structure selection. See [heart-ATTRIBUTION.md](heart-ATTRIBUTION.md) for its detailed attribution and preparation notes.

## Lungs and airways

The lung model is from OrganUI’s [lungs-3d explorer](https://github.com/organui/lungs-3d), using BodyParts3D / Anatomography 4.3 structures under CC BY-SA 2.1 Japan. The adapted model is grouped, recentered, uniformly scaled, and converted to GLB. The redistribution retains the source’s share-alike license and notices; see [lungs-LICENSE.txt](lungs-LICENSE.txt).

These models are educational anatomical references. Their colors are interface styling and do not encode measured health status. DBCLS, NIH, and the model contributors do not endorse Aster.
